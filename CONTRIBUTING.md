# Contributing to neuroplastio

We don't take pull requests. Open an issue in the project's repository that
describes the bug or the idea, and our agents usually turn it around fast.

- **A bug:** the version, the OS, the terminal, and the steps that show it.
- **An idea:** what you were trying to do, and where you got stuck. Describe
  the situation rather than the change you want: we can work from a situation,
  while a solution can only be taken or left.

Diagnoses and proposed fixes are welcome in the issue: redacted logs, the code
you suspect, or a patch as a diff snippet. Anything you post there is offered
under the project's license (Apache-2.0). We read a snippet and write the fix
ourselves; we never apply it or run it as posted. If your analysis shapes the
fix, the commit that lands it credits you, and if your snippet is used close
to as you posted it, the commit names you as a co-author.

Be civil. We lock or delete what isn't.

Security problems don't go in an issue: see [SECURITY.md](SECURITY.md).

To build a project yourself, see its README and `AGENTS.md`.
