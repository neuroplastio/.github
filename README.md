# neuroplastio/.github

The organisation's default community files. GitHub shows them on every
neuroplastio repository that has no file of its own:

- [`CONTRIBUTING.md`](CONTRIBUTING.md): issues, not pull requests;
- [`SECURITY.md`](SECURITY.md): reports go to security@neuroplast.io;
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/): the bug and idea forms.

A repository that keeps its own `CONTRIBUTING.md`, `SECURITY.md` or
`.github/ISSUE_TEMPLATE/` hides these, so projects don't.
